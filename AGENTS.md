# Agent Rules & Guidelines

## Editor Behavior & File Modifications
- **Do not open, reveal, or focus files in the editor**: When modifying or creating files, perform the required edits directly in place without triggering editor open or reveal actions.
- **Preserve active editor state**: Do not switch or disrupt the user's active editor document unnecessarily.
- **Explicit inspection only**: Only use editor-open or reveal actions if the user explicitly asks to view or inspect a specific file.
